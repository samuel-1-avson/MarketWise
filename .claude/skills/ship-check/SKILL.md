# Ship readiness checks

1. Read `EDITORIAL_ACCURACY_GUIDE.md`, `IMPLEMENTATION_CHECKLIST.md`, and `CLAUDE.md`.
2. Run available lint, TypeScript checks, unit, E2E, accessibility checks and production build; record actual outcomes and missing scripts.
3. Manually inspect all five lessons, six concept labs, every slide and mobile/presenter flows when test tooling allows.
4. Review source claims, all fictional values/labels, privacy and critical non-gambling/non-transaction scope.
5. Return a severity-ranked readiness report with evidence. Do **not** deploy, buy domains or connect external accounts without approval.
