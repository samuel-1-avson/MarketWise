# Frontend quality rules

- Strict types; no `any` without an explained exception.
- Functional interactive controls, semantic elements and explicit keyboard handling.
- Animated content must have a reduced-motion equivalent and remain interpretable without animations.
- Diagrams require short explanatory text and accessible controls.
- Synthetic numeric charts must display `Illustrative only — not live data` nearby.
- Preserve presenter position during lab detours; no duplicate slide IDs.
- Avoid API calls, sensitive data and any gambling/trading execution pathways.
